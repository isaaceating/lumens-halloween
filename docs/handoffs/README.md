# Task Handoffs

目前沒有並行任務或額外 worktree。

- [正式上線接續（2026-10-27）](2026-10-27-cloud-launch.md)

需要交接時，新增獨立的 `YYYY-MM-DD-task-name.md`，記錄：

- 目標、來源與日期。
- 實際專案路徑、branch、worktree、commit（尚無 commit 時明示）。
- 完成、未完成與受影響文件。
- 實際驗證、限制與風險。
- 下一步與需要確認的事項。

避免互相覆寫，不保存完整聊天、秘密或個人資料；總體現況見 [Project Status](../project-status.md)。
