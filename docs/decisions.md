## D004：照片、投票與視覺方向

- 日期：2026-10-27
- 狀態：已確認
- 來源：使用者本對話確認。
- 選擇：主辦人統一上傳照片；公司同仁每人一票；投票期間隱藏票數，截止後由主辦人統一公布；採 Whimsical Halloween 視覺方向。

## D005：工號投票與既有技術參考

- 日期：2026-10-27
- 狀態：工號需求已確認；框架及部署仍待選定。
- 來源：使用者本對話指出並非所有同仁都有 365 帳號。
- 選擇：使用工號投票，不要求 365 登入；若選 Next.js，對齊 Portal 技術架構。評估 GitHub Pages 與 my-lumens-star 的既有模式。
- 影響：初始 Supabase／Microsoft 登入提案不再是目前推薦。依已讀取的參考程式改評估 Firebase；只輸入工號的本人驗證限制及可選投票碼見 Architecture。

## D006：暫定架構與視覺 Demo

- 日期：2026-10-27
- 狀態：使用者暫定採用，先驗證視覺。
- 來源：本對話最新使用者指示。
- 選擇：GitHub Pages + Firebase；投票只輸入工號，不加投票碼；先製作本機靜態前端 demo。
- 影響：前端為 HTML/CSS/JavaScript，無 Next.js。工號不能證明本人；正式後端仍需核對資格、原子處理一票與限制讀取票數。此次不建雲端服務、不部署。

- 日期：2026-10-27
